# Erdős 第 272 题

[English](README.md) | **简体中文**

**Peihan Wu**

本仓库公开本人关于 [Erdős 第 272 题](https://www.erdosproblems.com/272)的研究论文。论文主张，对每个整数 $N\ge4000$，

$$
t(N)=\binom N2+1+\left\lfloor\frac{N-1}{4}\right\rfloor.
$$

这里 $t(N)$ 是 $[N]=\{1,\ldots,N\}$ 上互异子集族的最大大小，要求不同成员的交集均为非空等差数列。单点、二元集也视为等差数列；成员自身不必等差，亦不预设全族有公共点。上述范围包含 $N=4000$，不声称已完整解决所有更小参数或分类所有极值族。

## 4000以下的困难与方法局限

继续把门槛降到4000以下，在我的研究中仍然很困难。我为此投入了较长时间，目前围绕3800至4000只形成了进一步草稿。这些草稿尚未纳入当前论文的结论，本仓库不主张门槛已经降至3800。

在现有方法中，$N$ 较大时，结构约束带来的收益越来越能够压过边界项、例外配置和估计误差；随着 $N$ 变小，这些损耗占据的比例上升，需要更精细的结构估计才能维持论证余量。而得到这样的精细估计，并不是一件容易的事情。

本人预计，当 $N$ 降至几十到几百时，现有的结构估计路线可能会遇到实质障碍。这是我对当前方法的研究判断，并非关于小参数必然更难或该路线不可能改进的定理。继续推进可能需要新的结构思想、更细致地处理例外情形，或采用不同的严格计算方法。
